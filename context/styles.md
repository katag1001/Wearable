For women: 1. The fundamental outfit rules
Rule 1 — Balance volume
The simplest rule:

Voluminous top → slimmer or straighter bottom
Slim/fitted top → volume can go into the bottom
Oversized top + wide-leg bottom can work, but needs a deliberate fashion silhouette, usually with:
a shorter/cropped top
visible waist
structured footwear/accessories
or a relatively slim/short outer layer
Examples:

Hoodie + skinny jeans → easy
Hoodie + wide-leg jeans → possible, but better if hoodie is cropped or tucked
Fitted turtleneck + wide-leg trousers → excellent
Floaty blouse + wide-leg trousers → excellent if the waist is defined
Oversized cardigan + maxi skirt → works when the skirt is relatively fluid rather than bulky
Rule 2 — Define at least one part of the body
An outfit becomes easier to read when at least one of these is clear:

waist
shoulders
legs
neckline
ankles
This is particularly important when several oversized pieces are combined.

For example:

Oversized cardigan + wide-leg trousers + chunky shoes
can become shapeless.

But:

Oversized cardigan + high-waisted trousers + tucked fitted t-shirt
has a clear waist and looks intentional.

Rule 3 — Don't put volume everywhere by accident
The combinations most likely to look cumbersome are:

oversized hoodie + wide-leg trousers + bulky coat
chunky warm jumper + maxi skirt + oversized coat
oversized cardigan + boyfriend jeans + puffer
tunic + wide-leg trousers + long coat
They aren't forbidden. They simply need one strong structural counterpoint.

Rule 4 — Long over long needs intention
Long tops over long bottoms can work, but the proportions need to be controlled.

Particularly difficult:

tunic + maxi skirt
long turtleneck + maxi skirt
long cardigan + wide-leg trousers
long hoodie + wide-leg trousers
Better approaches:

create a waist
expose some leg/ankle
use a cropped outer layer
keep one piece slim
use a strong vertical line

24. Colour rules
Even without knowing the colours of your pieces, the system should follow these principles.

Rule 1 — Three colours maximum
A very reliable default:

1 dominant colour + 1 supporting colour + 1 accent.
Rule 2 — Neutrals make proportions easier
Black, white, cream, grey, navy, beige, brown and denim can be combined much more freely.

Rule 3 — Match temperature
Warm colours tend to work naturally with warm colours; cool colours with cool colours.

But deliberately contrasting temperatures can also be stylish.

Rule 4 — Repeat a colour
If an outfit has a strong colour, repeating it somewhere else creates cohesion.

For example:

burgundy blouse + neutral trousers + burgundy shoes/bag.
Rule 5 — Don't match everything
Perfectly matching top, trousers, coat, bag and shoes can look overly constructed.

Usually one or two colour echoes are enough.

30. The "don't duplicate bulk" rule
This is perhaps the most useful rule for automatic outfit generation.

Assign every item a rough volume score:

1 = fitted
2 = regular
3 = relaxed
4 = oversized
5 = extremely voluminous
Then avoid:

4 + 4 + 4
unless the goal is explicitly oversized fashion.

For example:

Fitted turtleneck (1) + wide-leg trousers (4) + structured coat (3) = excellent.

Oversized hoodie (4) + wide-leg jeans (4) + puffer (5) = risky.

Fitted bodysuit (1) + wide-leg trousers (4) + oversized coat (4) = much more balanced.
